## Part 2 - Responsive Design

The Genesys X Salon website was updated with responsive
web design features.

### Breakpoints

The website was tested at:

- Desktop
- Tablet
- Mobile

### Responsive Features

- CSS media queries
- CSS Grid
- Flexbox
- Relative units
- Responsive typography
- Responsive navigation
- Responsive images
- srcset
- sizes

### Layout

Desktop uses a multi-column layout.

Tablet uses a two-column layout.

Mobile uses a single-column layout.

### Testing

The website was tested using Chrome Developer Tools.

Screenshots were captured for:

1. Desktop
2. Tablet
3. Mobile
